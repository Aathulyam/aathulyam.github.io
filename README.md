# Athulyam Group — GitHub Pages

This repository hosts the official site at **https://aathulyam.github.io**.

## Structure
```
/assets
/css
/js
/images
index.html
```

## Deploy
1. Commit all files to the `main` branch of the `athulyam.github.io` repo.
2. In **Settings → Pages**, set Source to `main` and Directory to `/ (root)`.
3. The site will publish within a minute at your GitHub Pages URL.

## Customize
- Replace `images/athulyam-group-logo.png` with your official logo.
- Edit colors and effects in `css/styles.css`.
- Add pages or sections as the Group grows (TechWorks, Custom Machines, OS, Cybersafe, Forge).
